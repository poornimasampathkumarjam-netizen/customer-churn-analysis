# customer-churn-analysis
    An end-to-end Machine Learning project designed to predict customer attrition for a telecom company. This project evaluates customer behavior to calculate churn probabilities and predict high-risk subscribers, enabling businesses to take proactive retention actions.
 
## Key Highlights & Architecture
* **Predictive Modeling**:  Built and evaluated binary classification models using Decision Tree and Random Forest algorithms.
* **Risk Assessment**: Calculated the explicit statistical probability of churn for individual customer profiles alongside final predictions.
* **Feature Engineering**: Implemented One-Hot Encoding for categorical attributes and Standard Scaler for normalization of numerical metrics.
* **Quantitative Evaluation**: Benchmarked model performance strictly through Accuracy Score and Confusion Matrix analytics to ensure reliable business deployment.

## Tech Stack
* **Core Language**: Python
* **Data Processing**: Pandas, NumPy
* **Machine Learning**: Scikit-Learn (Jupyter Notebook Environment)
